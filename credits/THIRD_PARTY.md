# Third-party components

Last Terminus contains **no third-party art, audio, music or voice recordings**. Every model, texture, animation,
sound effect, music cue and spoken line was generated by the scripts in this repository. The following tools and
data were used to generate or run it:

| Component | Use | Licence |
|---|---|---|
| Godot Engine 4.7 | engine, exported runtime | MIT |
| Blender 5.2 LTS | headless procedural modelling, rigging, animation, glTF export | GPL (tool only; output is not covered) |
| Kokoro-82M (hexgrad) | text-to-speech model that synthesised all voices | Apache-2.0 |
| kokoro-onnx | inference wrapper | MIT |
| ONNX Runtime | inference | MIT |
| eSpeak NG | offline phonemizer used by the TTS pipeline | GPL-3.0 (tool only; no eSpeak audio ships) |
| FluidSynth | MIDI rendering of the composed music | LGPL-2.1 (tool only) |
| FluidR3 GM SoundFont | instrument samples used when rendering the music | MIT |
| Python, NumPy, SciPy, Pillow, mido, SoundFile | generators | PSF / BSD / HPND / MIT |
| FFmpeg, SoX | encoding, EQ, pitch shifting of the synthetic voices | LGPL / GPL (tools only) |
| Barlow, Barlow Condensed (Jeremy Tribby) | UI typefaces | SIL Open Font License 1.1 (`ui/fonts/*OFL*`) |
| Caveat (Impallari Type) | handwriting typeface for the notebook | SIL Open Font License 1.1 |

The voices are original synthetic voices (blends of Kokoro's voice embeddings with pitch/formant shaping).
No real performer or existing character was imitated. All characters, places, brands ("Toolbert's",
"Aligned Living", "Centennial Transit Center", "Safe-T-Bag") and events in the game are fictional.
